Practical 14: Page Replacement Algorithms and Virtual-Memory Performance

CO Mapping: CO5 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A cloud service provider hosts memory-intensive applications on servers with limited RAM. The operating system must efficiently manage memory while minimizing page faults and maximizing system performance. Develop a simulator implementing FIFO, LRU, Optimal, and Clock page replacement algorithms. Evaluate page-fault rate, hit ratio, memory utilization, Belady's Anomaly, and recommend an appropriate page replacement strategy for different workloads.

2. Key Questions / Analysis / Interpretation

Implementation How do FIFO, LRU, Optimal, and Clock page replacement algorithms differ? How do the number of frames affect page faults and hit ratio? What is Belady's Anomaly and which algorithms exhibit it? How does locality of reference influence memory performance? Interpret Linux memory statistics using free, vmstat, and /proc/meminfo. Compare theoretical and experimental page-fault behavior. Recommend a page replacement algorithm for desktop, database, cloud, and embedded systems with justification.

3. Supplementary Problems

Easy: Implement FIFO page replacement. Medium: Compare FIFO and LRU using different reference strings. Hard: Extend the simulator to include Working Set or Adaptive Replacement Cache (ARC) algorithm and compare performance.

4. Key Skills to be Addressed

Virtual memory management Page replacement algorithm implementation Performance evaluation Memory analysis Linux memory monitoring Operating system optimization CO5 29 | P a g e

5. Applications

Operating systems Cloud computing Database servers Virtualization platforms Embedded systems High-performance computing

6. Learning Outcome

Students will implement page replacement algorithms, analyze virtual memory behavior, evaluate memory performance using quantitative metrics, compare memory management strategies, and justify page replacement policies for practical operating system environments.

7. Dataset / Test Data

Use reference strings of length 20, 50, and 100 with locality-rich, random, and cyclic access patterns. Execute simulations using 3, 4, 5, and 8 page frames. Record page faults, page hits, hit ratio, execution time, memory utilization, and observe Belady's Anomaly where applicable.

8. Tools / Technology to be Used

Ubuntu 24.04 LTS GCC Compiler Linux Terminal C Programming Language free -h vmstat /proc/meminfo top Page Replacement Simulator

11. Post Laboratory Work Description

Prepare a comparative report on FIFO, LRU, Optimal, Clock, Working Set, and Adaptive Replacement Cache (ARC) algorithms. Compare implementation complexity, page-fault performance, scalability, memory overhead, and suitability for desktop, database, cloud, and virtualized systems.
