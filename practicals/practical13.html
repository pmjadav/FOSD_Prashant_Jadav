Practical 13: Banker's Algorithm for Deadlock Avoidance

CO Mapping: CO4 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A cloud computing platform allocates processors, memory, storage, and I/O resources to multiple virtual machines. The resource allocation mechanism must prevent deadlocks while maximizing resource utilization. Design and implement Banker's Algorithm to determine safe system states, evaluate dynamic resource requests, analyze allocation decisions, and recommend an effective deadlock avoidance strategy for resource-intensive systems.

2. Key Questions / Analysis / Interpretation

Implementation

  1. Differentiate safe state, unsafe state, and deadlock.
  2. How are the Allocation, Maximum, Need, and Available matrices computed?
  3. How does the Safety Algorithm determine a safe sequence?
  4. How does the Resource Request Algorithm evaluate new requests?
  5. Interpret the effect of increasing processes and resource types on algorithm performance.
  6. Compare deadlock avoidance, prevention, detection, and recovery techniques.
  7. Recommend an appropriate deadlock handling strategy for cloud computing and virtualization platforms.

3. Supplementary Problems

  • Easy: Compute the Need matrix from Allocation and Maximum matrices.
  • Medium: Determine a safe sequence for a given resource allocation.
  • Hard: Extend the implementation to process multiple simultaneous resource requests and compare execution time.

6. Learning Outcome

Students will implement Banker's Algorithm, evaluate safe and unsafe system states, analyze resource allocation decisions, compare deadlock handling techniques, and justify deadlock avoidance strategies for practical operating system environments.

7. Dataset / Test Data

Use datasets containing 3–10 processes and 3–6 resource types. Test multiple Allocation, Maximum, and Available matrices representing safe and unsafe system states. Execute additional resource requests and record safe sequences, execution time, resource utilization, and algorithm outcomes.

11. Post Laboratory Work Description

Prepare a comparative report on deadlock avoidance, prevention, detection, and recovery strategies. Study how Linux, Windows, virtualization platforms, and distributed cloud systems manage resources and minimize deadlock risk. Recommend the most appropriate strategy for large-scale computing environments.
