Practical 4: CPU Scheduling Simulation and Performance Evaluation

CO Mapping: CO2 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A cloud service provider hosts an online examination platform where thousands of student requests arrive simultaneously. The operating system scheduler must maximize CPU utilization, minimize waiting and response times, and ensure fairness among processes. Design and implement a CPU scheduling simulator supporting FCFS, SJF (Preemptive and Non- preemptive), Priority (Preemptive and Non-preemptive), and Round Robin scheduling. Evaluate scheduler performance using quantitative metrics and recommend the most appropriate scheduling policy for different workloads.

2. Key Questions / Analysis / Interpretation

Implementation Compare FCFS, SJF, Priority, and Round Robin scheduling algorithms. Interpret Waiting Time, Turnaround Time, Response Time and Throughput. How does the time quantum affect Round Robin performance? Which scheduling algorithm minimizes starvation? Which scheduler is most suitable for CPU-bound and I/O-bound workloads? Why does Linux use the Completely Fair Scheduler (CFS) instead of textbook algorithms? CO2 10 | P a g e Recommend an appropriate scheduler for cloud servers, multimedia systems, batch processing and real-time applications.

3. Supplementary Problems

Easy: Implement FCFS scheduling and draw the Gantt Chart. Medium: Compare Round Robin scheduling using different time quantum values. Hard: Extend the simulator to implement Multi-Level Feedback Queue (MLFQ) scheduling and compare its performance.

4. Key Skills to be Addressed

Scheduling algorithm implementation Performance analysis Algorithm comparison CPU utilization analysis Data interpretation Linux scheduler investigation Technical documentation

5. Applications

Operating system kernels Cloud computing platforms Real-time operating systems Embedded systems Database servers Multimedia streaming platforms Virtualization environments

6. Learning Outcome

Students will implement CPU scheduling algorithms, evaluate scheduling performance using quantitative metrics, interpret experimental observations, compare scheduling policies, and justify scheduler selection for diverse computing environments.

7. Dataset / Test Data

Create multiple process sets consisting of 5–20 processes with varying Arrival Time, Burst Time and Priority values. Include CPU-bound, I/O- bound and mixed workloads. Execute Round Robin using time quantum values of 2 ms, 4 ms, 8 ms and 16 ms. Record Waiting Time, Turnaround Time, Response Time, Throughput and CPU Utilization for each algorithm.

11. Post Laboratory Work Description

Prepare a comparative report on Linux Completely Fair Scheduler (CFS), Multi-Level Feedback Queue (MLFQ), and Earliest Deadline First (EDF) scheduling. Compare their objectives, fairness, latency, scalability, computational complexity, and suitability for interactive, batch, real-time and cloud computing systems.
