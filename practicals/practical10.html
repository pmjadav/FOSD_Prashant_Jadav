Practical 10: Named Pipes (FIFO) for Interprocess Communication

CO Mapping: CO2, CO6 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A centralized logging service receives events from multiple independent applications through a Named Pipe (FIFO). Design and implement interprocess communication using mkfifo(), open(), read(), write(), close(), and unlink(). Evaluate FIFO behavior in blocking and non-blocking modes, analyze throughput, latency, kernel buffering, and recommend suitable IPC mechanisms for different Linux applications.

2. Key Questions / Analysis / Interpretation

Implementation Differentiate anonymous pipes and FIFOs. How does a FIFO enable communication between unrelated processes? What is the effect of blocking and non-blocking modes on communication? How do message size and buffer capacity affect throughput and latency? Interpret FIFO behavior using strace, lsof and /proc. Compare FIFO with shared memory, message queues and UNIX domain CO2, CO6 21 | P a g e sockets. Recommend an IPC mechanism for logging, monitoring and client-server applications.

3. Supplementary Problems

Easy: Transfer a text message using a FIFO. Medium: Transfer a text file between two independent processes. Hard: Implement a simple chat application using two FIFOs for bidirectional communication.

4. Key Skills to be Addressed

Linux IPC programming FIFO programming Process synchronization Performance analysis Error handling Linux debugging tools

5. Applications

Logging systems Print spoolers Industrial automation Client-server applications Monitoring services Data acquisition systems

6. Learning Outcome

Students will implement FIFO-based IPC, evaluate communication performance, analyze synchronization behavior, compare IPC mechanisms, and justify the use of Named Pipes for Linux applications.

7. Dataset / Test Data

Use message sizes of 64 B, 1 KB, 4 KB and 64 KB. Transfer 100, 1,000 and 10,000 messages in blocking and non-blocking modes. Record throughput, latency, execution time, CPU utilization and communication errors.

8. Tools / Technology to be Used

Ubuntu 24.04 LTS GCC Compiler Linux Terminal POSIX APIs mkfifo(), open(), read(), write(), close(), unlink() strace lsof file time /proc file system

10. Total Hours of Engagement

11. Post Laboratory Work Description

Prepare a comparative report on Named Pipes (FIFO), Anonymous Pipes, POSIX Message Queues, System V Message Queues, Shared Memory and UNIX Domain Sockets. Compare scalability, persistence, latency, throughput, programming complexity and suitable application domains.
