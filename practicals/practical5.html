Practical 5: Thread Creation and Context-Switch Cost

CO Mapping: CO2, CO3 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A web server must handle thousands of simultaneous client requests while minimizing response time, memory consumption, and context-switch overhead. Develop a multithreaded application using POSIX Threads (Pthreads) to investigate concurrent execution, resource sharing, thread synchronization, and scalability. Compare thread-based execution with process-based and sequential execution, and recommend the most appropriate design for high-performance server applications.

2. Key Questions / Analysis / Interpretation

Implementation Differentiate processes and threads with respect to resource sharing and execution. How do pthread_create() and pthread_join() coordinate thread execution? How does increasing the number of threads affect execution time and CPU utilization? Interpret thread activity using ps -eLf, top -H, and /proc/<pid>/task. CO2, CO3 12 | P a g e Compare sequential, multiprocess, and multithreaded implementations. Explain context switching overhead in thread-based applications. Recommend an optimal threading strategy for multicore systems with justification.

3. Supplementary Problems

Easy: Create two threads that perform independent computations. Medium: Implement matrix addition using multiple threads. Hard: Develop a multithreaded matrix multiplication program and evaluate scalability on multicore processors.

4. Key Skills to be Addressed

POSIX thread programming Concurrent programming Context switching analysis Performance evaluation Thread synchronization Linux performance monitoring

5. Applications

Web servers Database management systems Parallel computing Scientific simulations Image and video processing Cloud and distributed computing

6. Learning Outcome

Students will implement multithreaded applications using POSIX Threads, analyze thread execution and context switching, evaluate scalability using quantitative performance metrics, and justify thread-based solutions for multicore computing environments.

7. Dataset / Test Data

Execute applications using 1, 2, 4, 8, and 16 threads. Use computational tasks such as matrix addition, matrix multiplication, large-array summation, and prime number generation. Record execution time, CPU utilization, memory usage, context switches, and speedup.

8. Tools / Technology to be Used

Ubuntu 24.04 LTS GCC Compiler Linux Terminal POSIX Threads (pthread) pthread_create() pthread_join() ps -eLf top -H htop perf stat /proc/<pid>/task

10. Total Hours of Engagement

11. Post Laboratory Work Description

Prepare a comparative study of POSIX Threads, OpenMP, Intel TBB, Java Threads, and Go Goroutines. Compare their programming models, scheduling mechanisms, scalability, synchronization techniques, and suitability for multicore and distributed systems.
