Practical 6: Deadlock & Banker’s Algorithm

Model resource allocation and perform deadlock avoidance using Banker’s algorithm.

Objective

Model resource allocation and perform deadlock avoidance using Banker’s algorithm.

Tasks
  1. Understand the relevant operating-system concept and identify its inputs, outputs and constraints.
  2. Design or implement the required experiment using an appropriate programming language/tool.
  3. Execute multiple test cases and record observations.
  4. Explain the observed behavior and relate it to OS design principles.
  5. Submit source code, output and a short analysis.
