Practical 15: Disk Scheduling Algorithms and Storage Performance

CO Mapping: CO6 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

Develop a simulator implementing FCFS, SSTF, SCAN, C-SCAN, LOOK and C-LOOK disk scheduling algorithms for a cloud storage server. Evaluate total head movement, average seek time, throughput, fairness and starvation, and recommend an appropriate scheduling policy for different storage workloads.

2. Key Questions / Analysis / Interpretation

Implementation How do FCFS, SSTF, SCAN, C-SCAN, LOOK and C-LOOK differ? How does request distribution affect head movement? Why can SSTF cause starvation? Compare HDD and SSD scheduling requirements. Interpret iostat, vmstat and /proc/diskstats output. Recommend an appropriate scheduler for different workloads.

3. Supplementary Problems

Easy: Implement FCFS. Medium: Compare SSTF and SCAN. Hard: Extend the simulator with BFQ or MQ-Deadline and compare performance.

4. Key Skills to be Addressed

Disk scheduling Storage performance analysis Algorithm comparison Linux storage monitoring Performance optimization Technical reporting

5. Applications

Operating systems Database servers Cloud storage File servers SAN Embedded storage

6. Learning Outcome

Students will implement disk scheduling algorithms, evaluate storage performance, compare scheduling strategies and justify scheduler selection for practical storage systems.

7. Dataset / Test Data

CO6 31 | P a g e Use request queues of 20, 50 and 100 cylinder requests with sequential, random and clustered access patterns. Measure total head movement, average seek time, throughput, fairness and starvation.

8. Tools / Technology to be Used

Ubuntu 24.04 LTS GCC Linux Terminal C iostat vmstat lsblk df /proc/diskstats

9. Total Hours of Problem Definition and Implementation

Activity Hours Problem Definition & Analysis 0.5 Implementation & Testing 1.5 Total 2.0

10. Total Hours of Engagement

Activity Hours Pre-laboratory Study 1 Laboratory Session 2 Result Analysis 1 Post-laboratory Work 1 Total 5

11. Post Laboratory Work Description

Prepare a comparative report on FCFS, SSTF, SCAN, C-SCAN, LOOK, C- LOOK, BFQ, Deadline and MQ-Deadline scheduling algorithms. Compare seek-time optimization, fairness, throughput, scalability and suitability for HDDs and SSDs.

12. Rubrics

Criterion Marks Problem Analysis 2 Implementation 3 Analysis & Interpretation 2 Supplementary Problem 1 Post Laboratory Work 1 Viva 1
