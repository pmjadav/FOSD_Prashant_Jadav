Practical 11: System V Message Queues

CO Mapping: CO2, CO6 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

An enterprise application consists of independent services that exchange structured messages. Design and implement interprocess communication using System V Message Queues. Develop sender and receiver programs using ftok(), msgget(), msgsnd(), msgrcv() and msgctl(). Evaluate communication latency, throughput, queue utilization, blocking behavior and message priorities, and recommend suitable IPC mechanisms for different workloads.

2. Key Questions / Analysis / Interpretation

Implementation How do System V Message Queues differ from pipes and FIFOs? How are message types used for priority-based communication? What is the effect of queue length on throughput and latency? How do blocking and IPC_NOWAIT modes affect execution? Interpret observations obtained using ipcs, ipcrm and strace. Compare System V and POSIX Message Queues. Recommend an IPC mechanism for asynchronous enterprise applications.

3. Supplementary Problems

Easy: Send and receive text messages. Medium: Exchange structures using message queues. Hard: Implement multiple producers and consumers using priority messages.

4. Key Skills to be Addressed

Linux IPC programming System V Message Queue programming Priority-based communication Performance analysis CO2, CO6 23 | P a g e Error handling Linux IPC administration

5. Applications

Enterprise applications Transaction processing systems Print servers Distributed services Industrial automation Asynchronous task scheduling

6. Learning Outcome

Students will implement System V Message Queue based IPC, evaluate message-oriented communication, analyze queue performance, compare IPC mechanisms, and justify message queue usage for enterprise applications.

7. Dataset / Test Data

Execute experiments using message sizes of 64 B, 256 B, 1 KB and 4 KB with 100, 1,000 and 10,000 messages. Test different message types and queue lengths. Record throughput, latency, queue occupancy, execution time and CPU utilization.

8. Tools / Technology to be Used

Ubuntu 24.04 LTS GCC Compiler Linux Terminal POSIX APIs ftok(), msgget(), msgsnd(), msgrcv(), msgctl() ipcs ipcrm strace time /proc file system

9. Total Hours of Problem Definition and Implementation

Activity Hours Problem Definition & Analysis 0.5 Implementation & Testing 1.5 Total 2.0

10. Total Hours of Engagement

Activity Hours Pre-laboratory Study 1 Laboratory Session 2 Result Analysis 1 Post-laboratory Work 1 Total 5

11. Post Laboratory Work Description

Prepare a comparative report on System V Message Queues, POSIX Message Queues, FIFOs, Shared Memory and UNIX Domain Sockets. Compare API design, persistence, scalability, latency, throughput and suitable application domains.
