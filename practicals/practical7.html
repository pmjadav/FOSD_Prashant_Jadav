Practical 7: Producer–Consumer Problem and Bounded Buffers

CO Mapping: CO3 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A multimedia streaming platform receives data from multiple producer threads while encoder threads consume it. Design and implement a bounded-buffer solution using POSIX mutexes and semaphores. Evaluate throughput, waiting time, synchronization overhead, and recommend an appropriate synchronization strategy.

2. Key Questions / Analysis / Interpretation

Implementation

  1. Why is synchronization required?
  2. How do mutexes and semaphores coordinate access?
  3. How does buffer size affect throughput?
  4. What happens when producer and consumer rates differ?
  5. Interpret CPU utilization and blocked threads.
  6. Compare single and multiple producer-consumer implementations.
  7. Recommend an optimal synchronization strategy.

3. Supplementary Problems

  • Easy: Single producer-consumer.
  • Medium: Multiple producers and consumers.
  • Hard: Compare semaphore-based implementation with a lock-free queue.

4. Key Skills to be Addressed

  • Concurrent programming
  • POSIX synchronization
  • Bounded-buffer implementation
  • Performance analysis
  • Linux debugging
  • Thread coordination

5. Applications

  • Operating system pipelines
  • Web servers
  • Streaming systems
  • Producer-consumer architectures
  • Data processing systems
  • Print spooling systems

6. Learning Outcome

Students will implement the Producer–Consumer problem, evaluate synchronization mechanisms, analyze buffer performance, and justify synchronization strategies for concurrent applications.

7. Dataset / Test Data

Use buffer sizes of 5, 10, 20 and 50 with 1, 2, 4 and 8 producers/consumers. Generate 1000, 10000 and 100000 items. Measure throughput, waiting time, CPU utilization and execution time.

11. Post Laboratory Work Description

Prepare a comparative study of semaphore-based bounded buffers, lock-free queues, circular buffers and message queues. Compare scalability, latency, throughput and synchronization overhead.
