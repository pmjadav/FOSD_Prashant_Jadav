Practical 2: Process Creation and Lifecycle Analysis

CO Mapping: CO2 · Laboratory session: 2 hours

Assessment: Each practical is assessed out of 10 marks. Students perform the experiment, record observations, complete supplementary work and answer viva questions.

1. Problem Definition

A software company is developing a build automation system similar to 'make'. The system must create child processes, execute compiler programs, synchronize execution and ensure linking begins only after successful completion of all compilation tasks. Develop a Linux application using fork(), exec(), wait() and waitpid() to study process creation, execution, synchronization and process hierarchy.

2. Key Questions / Analysis / Interpretation

Implementation Differentiate fork(), exec(), wait() and waitpid(). How does exec() change the process image? Explain parent-child relationships using process IDs. Compare execution with and without wait(). How are zombie and orphan processes created? Interpret observations from ps, pstree and /proc. Recommend an efficient process creation strategy for a build system.

3. Supplementary Problems

Easy: Create one child process and display PID and PPID. Medium: Create three child processes executing different Linux commands. Hard: Implement a simplified parallel build utility using fork(), exec() and wait().

4. Key Skills to be Addressed

Linux process management System call programming Process synchronization Process hierarchy analysis Debugging using Linux utilities Performance evaluation

5. Applications

Build automation tools Unix shell Web servers Batch processing systems Compiler toolchains Cloud task execution

6. Learning Outcome

Students will implement process creation and synchronization using Linux system calls, analyze process life cycles, interpret execution behaviour and justify process coordination strategies for real-world applications.

7. Dataset / Test Data

Execute programs with one, two and three child processes. Test Linux commands such as 'ls', 'pwd', 'date' and 'whoami' through exec(). Record PID, PPID, exit status, termination order and process tree using pstree, ps and /proc. CO2 7 | P a g e

8. Tools / Technology to be Used

Ubuntu 24.04 LTS GCC Compiler Linux Terminal POSIX APIs fork(), exec(), wait(), waitpid() ps pstree top strace /proc file system

9. Total Hours of Problem Definition and Implementation

Activity Hours Problem Definition & Analysis 0.5 Implementation & Testing 1.5 Total 2.0

10. Total Hours of Engagement

11. Post Laboratory Work Description

Prepare a comparative report on fork(), vfork(), clone() and posix_spawn(). Discuss memory usage, execution overhead, scalability and their suitability for modern operating systems.
