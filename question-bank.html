Question Bank

Conceptual, analytical, numerical and higher-order practice questions.

ArchitectureQ1. Compare a monolithic kernel and a microkernel for a system where reliability and performance are both important. Identify the design trade-offs.
ProcessesQ2. A system experiences frequent context switches. Analyze possible causes and explain how workload characteristics influence the effect on CPU utilization.
SchedulingQ3. Given a set of processes and burst/arrival times, calculate waiting, turnaround and response times under FCFS, SJF and SRTF.
Round RobinQ4. Analyze how changing the time quantum affects response time, context-switch overhead and throughput.
SynchronizationQ5. A producer-consumer implementation occasionally produces inconsistent output. Identify the possible race condition and propose a semaphore-based solution.
DeadlocksQ6. Given a resource-allocation state, determine whether the system is safe and justify the result using Banker’s algorithm.
MemoryQ7. For a specified partition layout and request sequence, compare first fit, best fit, worst fit and next fit in terms of fragmentation.
PagingQ8. Translate logical addresses into physical addresses using a given page table and page size. Explain the role of the TLB.
TLBQ9. Given TLB hit ratio, TLB access time and memory access time, derive the effective memory access time.
Real-timeQ10. Compare EDF and RMS for a periodic task set and explain which scheduling constraints must be checked.
