Foundation Topics

Bridge Topics & Self-Study

Topics identified in the supplied CEUC301 syllabus.

Instruction Cycle & Context Switching

Instruction cycle and execution, timer interrupts, and hardware-level context switching.

OS Functionalities & Objectives

Operating system functionalities, objectives, and operating system types.

Memory Hierarchy & Address Translation

Memory hierarchy and address translation as preparation for memory-management topics.

Memory Layout in C

Text, data, heap, and stack memory layout, preferably using the C language.

Locking in DBMS

Database locking concepts that provide background for synchronization and concurrency control.

Cache vs. Virtual Memory

Comparison of cache and virtual-memory concepts as preparation for memory-system design.

Hardware Synchronization Primitives

Hardware synchronization primitives supporting concurrency-control concepts.

File Systems & Indexing

File-system concepts and indexing structures as preparation for file-system design.

Suggested useReview these foundation topics before the corresponding lecture unit. The syllabus recommends connecting internal OS mechanisms to practical implementation and performance analysis.
