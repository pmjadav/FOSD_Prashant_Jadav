Curriculum

Course Units

Core areas covered by the course.

01

OS Introduction & Architecture

OS goals, types, kernel architectures, system calls and modes.

02

Processes & Threads

Process image, PCB, states, context switching, threads and TCB.

03

CPU Scheduling

FCFS, SJF, SRTF, RR, priority, multilevel queues, EDF and RMS.

04

Synchronization & Deadlocks

Concurrency, synchronization mechanisms and deadlock strategies.

05

Memory Management

Partitioning, fragmentation, paging, segmentation, TLB and virtual memory.

06

File Systems & I/O

File organization, allocation, disk scheduling, buffering and journaling.

07

Specialized Operating Systems

Real-time, embedded, mobile and distributed OS design considerations.
